# Sitio web de M&G Consultoría Legal

Sitio estático publicado con GitHub Pages en https://mgconsultorialegal.com.mx/

- `index.html`: la página completa (HTML y CSS en un solo archivo).
- `assets/`: logo y foto.
- `CNAME`: dominio personalizado. No borrar.
- `fuente/contenido.py`: textos, servicios y precios. Después de editarlo, corre
  `python fuente/construir.py` y sube los cambios.
- `fuente/originales/`: logo y foto originales. `python fuente/preparar_imagenes.py`
  regenera `assets/`.
